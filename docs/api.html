Functions and methods

All classes and functions are in the CmdStan namespace. Standalone functions keep CmdStanR’s snake_case names. Methods and their parameters are camelCase, so CmdStanR’s fit$output_files() is $fit->outputFiles(), and Compatibility maps every renamed method. CmdStan’s option names are unchanged.

Inference methods accept PHP named arguments or one associative options array, and they reject unknown options. An option left out or set to null uses the installed CmdStan’s default.
