Helper classes

Classes for figures, in-process model code, and statistics on plain arrays. Their methods are camelCase.

Figures

Figure

Returned by the figure functions and Plot. The statistics are computed once, so every rendering shows the same numbers. Casting a figure to a string gives ascii().

Method Purpose
->ascii() Text rendering. null sizes use per-kind defaults.
->vegaLite() Vega-Lite spec with the data inlined. Sizes are in pixels, per facet for per-chain figures. maxRows thins trace and scatter data by keeping every k-th row.
->json() The spec as JSON, safe to embed in an HTML script element.
->html() A standalone HTML page that renders the spec with vega-embed from the jsDelivr CDN.
->svg() SVG through the vl-convert binary, found through VL_CONVERT or PATH.
->png() PNG bytes through vl-convert at scale.
Signatures 
ascii(?int $width = null, ?int $height = null): string
vegaLite(int $width = 480, int $height = 240, ?int $maxRows = null): array
json(int $width = 480, int $height = 240, ?int $maxRows = null): string
html(int $width = 480, int $height = 240, ?int $maxRows = null): string
svg(int $width = 480, int $height = 240, ?int $maxRows = null, ?float $timeout = 60.0): string
png(int $width = 480, int $height = 240, ?int $maxRows = null, float $scale = 2.0, ?float $timeout = 60.0): string

Plot

Static methods. Draws come from a fit or a draws_array. Densities use a Gaussian kernel with R’s bw.nrd0 bandwidth on 512 points, quantiles use R’s type 7 rule, and ranks average ties.

Method Purpose
Plot::trace() Chains overlaid by iteration (mcmc_trace()).
Plot::hist() Histogram of all draws (mcmc_hist()).
Plot::dens() Kernel density of all draws, or of each chain with byChain (mcmc_dens(), mcmc_dens_overlay()).
Plot::intervals() Inner and outer intervals with a point estimate (mcmc_intervals()).
Plot::rankHist() Rank histogram of each chain (mcmc_rank_hist()).
Plot::scatter() Joint draws of two variables (mcmc_scatter()).
Plot::acf() Autocorrelation of each chain (mcmc_acf()).
Plot::paretoK() Pareto k by observation (pareto_k_plot()).
Plot::bandwidth() R’s bw.nrd0 bandwidth.
Plot::density() Gaussian kernel density of x at each point of at.
Plot::autocorrelation() Autocorrelations for lags 0 to lags, as R’s acf().
Plot::ranks() One-based ranks with ties averaged, as R’s rank().
Plot::range() The data range, padded when every value is equal.

Model methods and Stan functions

StanFunctions

Returned by exposeFunctions(). Arguments and results use PHP numbers and zero-indexed lists: vectors and arrays are lists, matrices are lists of rows, complex numbers are [re, im], and tuples are lists. Call a function as a method, such as $f->add(1.5, 2). Needs the FFI extension.

Method Purpose
StanFunctions::compile() Compile, or reuse, the functions library for a Stan file. Libraries are cached beside the file.
->functions() Each function’s return_type, arguments, rng, supported, and reason, with Stan type names.
->call() Call a function with positional or named arguments. _rng functions also accept seed.
->library() The compiled library path.
Signatures 
compile(string $stanFile, array $stancOptions = [], ?string $outputDir = null, ?float $timeout = null): self
functions(): array
call(string $function, mixed ...$arguments): mixed
library(): ?string

ModelMethods

What a fit’s model methods use, without a fit. Densities drop constants, as in CmdStanR. Named variables are nested zero-indexed lists, and unconstrained vectors are flat lists. Needs the FFI extension.

Method Purpose
ModelMethods::compile() Build, or reuse, the library for a Stan file and bind it to data.
ModelMethods::build() Build, or reuse, the library and return its path.
new ModelMethods() Bind a built library to data: an array, a StanData, a table, or a JSON file.
->logProb() Log density at unconstrained values.
->gradLogProb() log_prob and gradient.
->hessian() log_prob, grad_log_prob, and hessian, by finite differences of autodiff gradients.
->unconstrainVariables() A flat unconstrained list from values keyed by parameter name.
->unconstrainDraws() Unconstrained rows from draw rows keyed by names such as x[1,2].
->constrainVariables() Constrained values keyed by variable.
->unconstrainedParamNames() Unconstrained parameter names, such as s[1].
->constrainedParamNames() Constrained names in CmdStan CSV column order.
->variableSkeleton() Each variable’s dimensions: [] for scalars, a trailing 2 for complex values.
->numUnconstrained() The number of unconstrained parameters.
->seedRng() Reseed the generator that constrainVariables() uses for generated quantities.
->seed() The current seed.
->library() The library path.

Summary::percent() A probability formatted as posterior names quantiles, such as 5 for 0.05.

Loo::waic() WAIC: estimates, pointwise rows, and warnings.

Loo::relativeEff() loo’s relative_eff() for likelihood values.
Loo::relativeEffLogLik() Relative efficiencies from log-likelihood values, as CmdStanR computes them.
Loo::paretoKTable() Counts, proportions, and minimum n_eff per Pareto k interval.
